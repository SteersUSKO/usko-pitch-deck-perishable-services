# USKO × Expeditors International: Perishable & Pharmaceutical Pitch Deck

React slide deck built with Vite. All files sit at the top level of the repository (no folders needed).

## Files

- `App.jsx`: all slide content
- `styles.css`: all styling
- `main.jsx`: starts the app
- `index.html`: page shell and link-preview tags
- `vite.config.js`, `vercel.json`, `package.json`, `package-lock.json`: build settings

## Deploy

Upload all files to the top level of a GitHub repository and import it into Vercel. No settings need to be changed.

## Run locally

```
npm install
npm run dev
```
